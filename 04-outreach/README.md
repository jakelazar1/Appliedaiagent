## THE OUTREACH PROCESS AT A GLANCE

```
PROSPECT JOURNEY

[1] ADD PROSPECT
    ├─ Research (use 03-QUICK ref: Qualification Quick Score)
    ├─ Qualify (score 0-20, >12 = pursue)
    └─ Add to database

[2] SEND MESSAGE 1 (Initial Awareness)
    ├─ Personalized cold email
    ├─ No commitment ask (15-min call?)
    └─ Track opens/clicks

[3] 7 DAYS LATER: SEND MESSAGE 2 (Problem + Outcome)
    ├─ Lead with specific value (hours saved, $ impact)
    ├─ If opened: higher priority follow-up
    └─ Track responses

[4] 14 DAYS LATER: SEND MESSAGE 3 (Social Proof)
    ├─ Use specific case study/competitor win
    ├─ Create light urgency (limited availability)
    └─ If response: Move to assessment

[5] ASSESSMENT CALL (15 min)
    ├─ Use script from 02-IMPLEMENTATION (full version)
    ├─ Discover pain points, tools, WTP
    ├─ Decide: Demo? Proposal? No fit?
    └─ Send custom brief after call

[6] DEMO (20-30 min)
    ├─ Show working system (custom-tailored)
    ├─ Gather feedback
    └─ If interested: Move to proposal

[7] PROPOSAL (Written)
    ├─ Scope, timeline (2-3 weeks), pricing, terms
    ├─ Include case study + risk mitigation
    └─ Send with context email

[8] NEGOTIATION (If needed)
    ├─ Adjust scope/price/timeline
    ├─ Stay firm on embedded approach
    └─ Find mutual win

[9] SIGNED & IMPLEMENTATION
    ├─ 2-3 week custom build phase
    ├─ Weekly demos + feedback loops
    ├─ Launch week: full support + training
    └─ Month 1+: Monthly optimization

METRICS TO TRACK AT EACH STAGE:
├─ % moving to next stage (conversion rate)
├─ Average sales cycle length (days)
├─ Average deal value
├─ CAC payback period
└─ Win/loss reasons
```

## VERTICALS RANKED BY EASE OF ENTRY

**Start with easier verticals first, then add harder ones:**

1. **Tour Operators** ✅ EASIEST
   - Clear pain (bookings), good WTP, tight-knit community
   - Strong messaging angle
   - Easy to find prospects online
   - Fast decision timelines

2. **Real Estate** ✅ EASY
   - Huge pain (lead follow-up), very active online
   - Good WTP, multiple decision makers
   - Strong messaging
   - Large market = many prospects

3. **Hospitality** ✅ EASY
   - Acute pain (24/7 communication), recession-resistant
   - Easy to find/qualify
   - Good messaging ("no staff needed")
   - Natural seasonal urgency

4. **Salons** ✓ MEDIUM
   - Clear pain (phones + no-shows)
   - Slightly lower WTP, many prospects
   - Good messaging but slight pushback on price
   - Faster sales cycle

5. **HVAC** ✓ MEDIUM
   - Big pain but more complex tech stack
   - Good WTP, seasonal urgency
   - Slightly longer sales cycle
   - Good prospects available

6. **Auto Repair** ✓ MEDIUM
   - Clear pain (service advisor overwhelm)
   - Complex workflows, longer sales cycle
   - Good WTP, but need to find prospects offline
   - Slightly more consultative

7. **Landscaping** ✓ MEDIUM
   - Seasonal, clear pain, lower WTP
   - Harder to find qualified prospects
   - Price-sensitive decision makers
   - Faster close but lower deal values

8. **Accounting** ✗ HARDER
   - Pain less clear (need to educate)
   - Lower WTP, longer sales cycle
   - Multiple decision makers
   - More consultative sales

9. **Coaching** ✗ HARDEST
   - Pain less tangible, lower WTP
   - Smaller market, harder to find
   - Longer sales cycle, more objections
   - Solo practitioners often DIY-oriented

**Recommendation:** Start with #1-3, add #4-5 after first month, add #6-9 only after you have 2-3 case studies.

## COMMON PITFALLS TO AVOID

1. **Generic outreach**
   - ✗ Wrong: "I help businesses automate with AI"
   - ✓ Right: "I noticed you run tours through FareHarbor. Your team probably handles 15+ hours/week of booking questions..."

2. **Too aggressive follow-up**
   - ✗ Wrong: Emailing daily, calling multiple times
   - ✓ Right: Message 1 → +7 days Message 2 → +7 days Message 3 → graceful exit

3. **Premature demo**
   - ✗ Wrong: Offering demo before you understand their problem
   - ✓ Right: Assessment → Custom brief → Demo only if they're interested

4. **Wrong messaging for vertical**
   - ✗ Wrong: Same email for tour operators and accountants
   - ✓ Right: Customize pain point, tool mention, and WTP for each

5. **Not tracking results**
   - ✗ Wrong: Sending emails without tracking opens, clicks, responses
   - ✓ Right: Every prospect tracked in database, daily updates

6. **Giving up too early**
   - ✗ Wrong: 1-2 responses and then move on
   - ✓ Right: Full 3-email sequence + 21-day cycle before moving to "no fit"

7. **Price negotiating too early**
   - ✗ Wrong: Discussing price in first email
   - ✓ Right: Focus on fit first, price later

8. **Not following the process**
   - ✗ Wrong: Skipping assessment, going straight to demo
   - ✓ Right: Assessment → Custom brief → Demo → Proposal (in order)
