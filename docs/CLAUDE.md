## Website Rewrite Goals

The current site (index.html, work.html, contact.html) is generic — it mentions
plumbing, landscaping, HVAC. That needs to change. The redesign should:

1. **Lead with Sonoma wine country** — this is my home turf and my credibility.
   The headline, subheadline, and hero copy should speak to wine country businesses.

2. **Show my background as the differentiator** — I'm not a generic tech consultant.
   I'm a winemaker who also builds AI. That's the hook. Use it.

3. **Name specific automations** — the work section should show the wine-country-specific
   systems listed above, not generic plumbing/landscaping examples.

4. **Keep the design language** — the existing typography (Fraunces + Manrope),
   color palette (cream, dark, gold), and layout structure are excellent. Do NOT
   change the visual design. Only change the copy, messaging, niche focus, and
   the work/portfolio examples.

5. **Update the industry dropdown in the demo modal** — replace the current options
   (Construction, Plumbing, HVAC, etc.) with wine country and broader hospitality
   options:
   - Winery / Tasting Room
   - Wine Tour Operator
   - Vineyard / Estate
   - Hospitality / Hotel
   - Restaurant / Bar
   - Home Services
   - Real Estate
   - Legal / Professional Services
   - Other

6. **Update footer year** — change 2025 to 2026.

7. **Keep all three pages** — index.html (home), work.html (portfolio), contact.html.
   Apply consistent messaging across all three.
