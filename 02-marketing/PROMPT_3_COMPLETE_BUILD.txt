YOUR TASK (Phased Approach):
============================

PHASE 1: PROJECT SETUP (Hours 1-4)
----------------------------------
1. Create Next.js 14 project with TypeScript
2. Configure Tailwind CSS with the design tokens from the brief
3. Set up folder structure as specified in the developer brief
4. Install dependencies (Framer Motion, React Hook Form, Zod)
5. Create globals.css and CSS custom properties (variables.css)
6. Configure eslint/prettier

PHASE 2: LAYOUT SHELL (Hours 5-12)
----------------------------------
1. Build Header component (fixed/sticky, responsive, logo, nav, CTA button)
2. Build Footer component (4-column layout, links, contact, copyright)
3. Build Navigation component (desktop + mobile-responsive)
4. Create page.tsx with section container structure
5. Ensure full-page layout works with proper spacing/margins

PHASE 3: HERO SECTION (Hours 13-24)
-----------------------------------
1. Create HeroSection component with:
   - Full-viewport design (height: 100vh or 90vh on mobile)
   - Headline + subheadline (positioned left or center, your choice)
   - Abstract visual (SVG or CSS gradient animation - NOT stock photo)
   - Scroll indicator (chevron or arrow, animated)
   - Staggered text entrance animations (each element fades in sequentially)
   - Responsive adaptation for mobile (smaller headline, adjusted visual)
2. Implement animations using Framer Motion:
   - Container: stagger children
   - H1: fade in + slide up
   - Subheading: fade in + slide up (delayed)
   - Visual: fade in (slower)
   - Scroll indicator: pulse animation
3. Test on mobile/tablet/desktop for visual impact
